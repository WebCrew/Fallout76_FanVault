# Troubleshooting

- Icon not centred: saved placement takes precedence. Look at the previous position and try Ctrl+Shift+F; do not delete saved files automatically.
- Chat unavailable: production disables the demo; real Net-Twin integration is not implemented. Quit fully and use development/test for the local demo.
- Startup config error: check the three documented environment variables. Unsupported games/environments and secret-bearing or insecure remote URLs are rejected.
- Environment unchanged on second launch: quit the first instance completely before restarting.
- Image disappears or is not delivered: only a local preview exists.
- Exclusive fullscreen hides overlay: try windowed/borderless and report the mode; universal game compatibility is not guaranteed.

Report candidate version and steps. Redact private profiles/messages and tokens from screenshots/logs. Never share local credential TXT files.
