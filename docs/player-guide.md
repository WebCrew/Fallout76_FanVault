# Player guide — Windows prototype

Demo members and messages are not signed-in Net-Twin players. Do not enter real passwords or private messages.

1. Extract the Windows build artifact and start its EXE. On first run the round **76** icon appears near the centre of the primary display; existing saved placement takes precedence.
2. Click to open the complete current chat panel. Drag the icon or the panel title to keep the game's HUD clear.
3. Resize using the panel's lower-right grip. Size and position are saved and constrained to display work areas.
4. Ctrl+Shift+F hides/shows the overlay. Collapse with the close control or Escape while typing. Menu → Exit or Ctrl+Shift+Q asks to quit completely.

The local chat starts automatically in the default demo. It does not exchange messages with Net-Twin or other PCs. Images are local previews. Voice/squads are unfinished; Ctrl+Shift+E is not implemented.

Test Fallout 76 in windowed/borderless mode. Visibility over exclusive fullscreen is not guaranteed. No game-process injection is introduced by this step.

The intended real service requires a Net-Twin account and relevant game/platform gamertag in profile settings. Creating a group/page or generating an API key is not required for ordinary use.
